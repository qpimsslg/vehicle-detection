# Vehicle Detection

Приложение для детекции транспортных средств на изображениях с использованием моделей YOLO, 
обученных на датасете VisDrone (съёмка с дрона).

## Демо

🚀 [Открыть приложение на Hugging Face Spaces](https://huggingface.co/spaces/qpimsslg/vehicle-detection)

## Применение

Детекция транспорта с воздуха востребована в задачах:
- **Мониторинг дорожного трафика** – подсчёт и классификация транспорта
- **Умные города** – анализ загруженности парковок и перекрёстков
- **Безопасность территорий** – наблюдение за крупными объектами
- **Логистика** – отслеживание транспорта на складских территориях

## Классы детекции

| Класс | Описание |
|-------|----------|
| car | Легковой автомобиль |
| van | Микроавтобус / минивэн |
| truck | Грузовик |
| tricycle | Грузовой трёхколёсный велосипед |
| awning-tricycle | Трёхколёсный велосипед с тентом |
| bus | Автобус |
| motor | Мотоцикл / мопед |

## Модели

Обе модели обучены на [VisDrone Dataset](https://github.com/VisDrone/VisDrone-Dataset), 
7 классов транспортных средств, 100 эпох, imgsz=1024.

| Модель | mAP50 | Скорость инференса |
|--------|-------|--------------------|
| YOLOv8s (точная) | 0.538 | ~7ms/img |
| YOLOv8n (быстрая) | *в процессе обучения* | ~3ms/img |


## Стек

- **Модели:** YOLOv8 (ultralytics)
- **Интерфейс:** Streamlit
- **Детекция:** запускается в отдельном потоке, интерфейс не блокируется
- **Деплой:** Hugging Face Spaces (Docker)

## Локальный запуск

```bash
git clone https://github.com/qpimsslg/vehicle-detection
cd vehicle-detection
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Модели скачать вручную и положить в папку `models/`.
- `visdrone_yolo26_accurate.pt` – точная модель
- `visdrone_yolo26_quick.pt` – быстрая модель
