# Vehicle Detection

## Описание
Данный проект реализует систему детекции объектов с использованием моделей YOLO для 
детекции транспортных средств на изображениях. Он включает в себя FastAPI сервер для обработки 
запросов и Streamlit интерфейс для взаимодействия с пользователем.

Проект выполняется в рамках курса Deep Learning School (DLS).

Проект предназначен для классификации транспортных средств на изображениях, таких как:
1. car
2. van
3. truck
4. tricycle
5. awning-tricycle
6. bus
7. motor

Для обучения моделей использовался датасет VisDrone, доступный на [Kaggle](https://www.kaggle.com/datasets/kushagrapandya/visdrone-dataset)

## Стек технологий

### Обучение:

* YOLO (You Only Look Once) — используется для детекции объектов. Модели, обученные на датасете VisDrone, применяются для классификации транспортных средств на изображениях.

### Бэкенд:

* FastAPI — используется для создания API, который обрабатывает запросы от клиента (Streamlit) и выполняет детекцию объектов на изображениях.

* Uvicorn — ASGI сервер, используемый для запуска FastAPI приложения.

### Интерфейс:

* Streamlit — используется для создания простого и удобного интерфейса, через который пользователи могут загружать изображения, выбирать модели для детекции и видеть результаты

# Установка и запуск
1. **Клонирование репозитория**

Склонируйте репозиторий на свою локальную машину:

```
git clone https://github.com/qpimsslg/vehicle-detection.git
cd vehicle-detection
```

2. **Установка зависимостей**

На данный момент репозиторий дорабатывается, поэтому файл requirements.txt пока не доступен.
Создайте виртуальное окружение и установите зависимости:

```
python -m venv venv
source venv/bin/activate  # для Linux/Mac
.\venv\Scripts\activate   # для Windows
pip install -r requirements.txt
```

3. **Запуск FastAPI сервера**

Для запуска FastAPI сервера используйте Uvicorn:

```
uvicorn app.main:app --reload
```

Сервер будет доступен по адресу http://127.0.0.1:8000.

4. **Запуск Streamlit приложения**

Для запуска интерфейса Streamlit:
```
streamlit run streamlit_app.py
```
Интерфейс будет доступен по адресу http://localhost:8501

5. **Использование**

1) Загрузите изображение для детекции.

2) Выберите модель для обработки (быстрая или точная).

3) После обработки изображение с детекцией объектов (bounding boxes) будет отображено на странице.

## Важные моменты

* Модели YOLO: Для выполнения детекции используются предобученные модели YOLO. Они находятся в папке models/ и были обучены на датасете VisDrone.
* Папка uploads: В этой папке сохраняются как исходные изображения, так и обработанные изображения с результатами детекции.
* Форматы файлов: На данный момент поддерживаются изображения форматов JPEG, PNG и WEBP.
