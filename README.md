# Vehicle Detection

Учебный ML-проект по задаче детекции автотранспорта на изображениях.
Репозиторий создан в рамках курса Deep Learning School (DLS).

Репозиторий содержит описание задачи и
планируемого подхода к ее решению.

**Ориентировочный срок сдачи проекта:** 08.02.2026

---

## Идея проекта

Цель проекта — изучить и применить подходы к детекции
автотранспортных средств на изображениях с использованием
методов глубинного обучения.

В рамках проекта планируется:
-формулировка задачи детекции автотранспортных средств на изображениях и анализ требований;
- выбор и сравнение моделей для детекции объектов;
- обучение и оценка моделей на открытых датасетах;
- (опционально) разработка простого интерфейса для демонстрации работы модели.

---

## Данные

В качестве источников данных рассматриваются открытые датасеты
для задачи детекции объектов, в том числе:
- VisDrone
- Open Images
